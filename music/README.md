# 背景音樂

依語音情緒自動挑選的背景音樂 (見 `bgm.py`)。音檔本身不放進 repo，請自行準備純音樂 (無人聲) 放進對應資料夾，
支援 mp3 / wav / m4a / aac / ogg / flac，同一資料夾放多首時會隨機挑一首。

| 資料夾 | 對應情緒 | 建議曲風 |
|---|---|---|
| `negative(sad_angry)/` | 生氣、傷心、害怕 | 溫暖鋼琴、lo-fi、木吉他等安撫型音樂 |
| `positive(happy)/` | 開心 | 烏克麗麗、輕快木吉他等明亮音樂 |

中性等其他情緒不播放背景音樂；資料夾是空的時也會自動略過，不影響影片生成。
